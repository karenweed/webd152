Sample Description List

TCP
Transmission Control Protocol is a method (protocol) used along with the Internet Protocol (IP) to send data in the form of message units between computers over the Internet.
IP
Internet Protocol is the method or protocol by which data is sent from one computer to another on the Internet.
FTP
File Transfer Protocol is a protocol used to exchange files between computers on the Internet.
HTTP
Hypertext Transfer Protocol is the protocol used for exchanging or transferring hypertext.
